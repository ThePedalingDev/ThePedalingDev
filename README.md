## <img src="./assets/v2/section.svg" alt="" width="18" height="18" /> What I work in

My day to day is React and TypeScript at the front, and ASP.NET Core or Node with Postgres behind it. Cloud came once I had something worth hosting, and mobile with Flutter, which I'm building on Skillance.

- **Front end and web:** HTML, CSS, JavaScript, TypeScript, React, Tailwind CSS, Next.js, GSAP
- **Back end and data:** Node.js / Express, C#, ASP.NET Core, EF Core, SQL, PostgreSQL, MS SQL, MongoDB, Supabase, REST / OpenAPI, Python
- **Cloud and ops:** Linux, Docker, Nginx, GitHub Actions, Azure, Cloudflare (Turnstile, CDN, proxy, tunnels)
- **Mobile:** Flutter, with iOS and Android experiments
- **Learning now:** Three.js, Go
